# MDK0401
# Цели внедрения Складского учёта
Создание прозрачной, управляемой системы складского учёта, обеспечивающей современное снабжение производства и отгрузку клиентов без нарушения сроков и качества.
# Содержание плана внедрения 
# Этап 1 Диагностика
1.1 Аудит текущих бизнес-процессов склада 
1.2 Интервью с ключевыми сотрудниками 
1.3 Определение функциональных требований к системе 
Результат: Техническое задание, карта текущих процессов, план-график работ
# Этап 2 Проектирование 
1.1 Выбор программного продукта
1.2 Разработка архитектуры решения: описание автоматизируемых процессов 
1.3 Проектирование схемы интеграции 
1.4 Определение потребности в оборудовании  
# Этап 3 Адаптация 
1.1 Настройка хранения 
1.2 Настройка правил размещения 
1.3 Настройка прав доступа 
# Этап 4 Обучение 
1.1 Проведение тестового запуска системы на 1 складе 
1.2 Тестирование сценариев 
1.3 Выявление ошибок и их устранение 
1.4 Аттестация персонала 
# Этап 5 Запуск 
1.1 Финальная загрузка данных 
1.2 Организация поддержки 
1.3 Ежедневный мониторинг 
# Сроки выполнения (15 дней)
1. Диагностика (2 дня)
2. Проектирование (6 дней)
3. Адаптация (1 день)
4. обучение (4 дня)
5. Запуск (1 дня)
# Ответственность и ресурсы
1. Руководитель проекта
